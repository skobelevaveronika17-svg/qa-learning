2. есть чекбокс "Запомнить меня"
3. кнопка "Войти"

7. Иконка «показать» раскрывает пароль

## Блокировка после 5 попыток
17. Ввод 5 неверных попыток → ошибка

19. Ввод 6 неверных попыток → невозможен

## Клавиатура

48. Войдет  в личный кабинет, если скопировать пароль и вставить → вход
49. Работает автозаполнение → вход
50. После выхода из браузера выходит из личного кабинета → выход из личного кабинета
## Безопасность
51. Ввести ' OR 1=1 -- в поле email → ошибка формата, вход не выполняется, текст ошибки базы не показывается
52. Ввести >script>alert(1)</script< в поле email → текст показывается как текст, окно не появляется
53. Ввести пароль, открыть код страницы (F12) → значение пароля в разметке отсутствует
54. Выполнить вход → пароль не появляется в адресной строке, страница работает по https
55. Выйти из системы, нажать «Назад» → открывается форма входа, данные личного кабинета не показываются

## Поведение системы
56. Двойной клик по "Войти" → форма отправляется один раз, кнопка блокируется на время запроса.
57. Индикатор загрузки во время запроса → пока идёт запрос, виден индикатор, кнопка неактивна.
58. Обрыв сети → сообщение "Нет соединения"
59. Открыть форму в Chrome, Firefox и Edge → вёрстка и вход работают одинаково
60. Войти в Chrome, затем войти тем же аккаунтом в Firefox → обе сессии живут, из первой не выкидывает
61. при увеличении до 200% форма читается целиком, поля не наезжают друг на друга, кнопка «Войти» остаётся доступной.
