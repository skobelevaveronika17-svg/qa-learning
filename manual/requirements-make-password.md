1. make_password(8) возвращает строку длиной ровно 8 символов,
   в которой есть хотя бы одна цифра и хотя бы одна заглавная буква.
   Проверка: len(make_password(8)) == 8
2. make_password(20) возвращает строку длиной ровно 20 символов,
   в которой есть хотя бы одна цифра и хотя бы одна заглавная буква.
   Проверка: len(make_password(20)) == 20
3. make_password(8, has_upper=False) возвращает строку длиной 8,
   в которой нет ни одной заглавной буквы, но есть цифра.
   Проверка: make_password(8, has_upper=False) == "aaaaaaa1"
4. make_password(8, has_digit=False) возвращает строку длиной 8,
   в которой нет ни одной цифры, но есть заглавная буква.
   Проверка: make_password(8, has_digit=False) == "Aaaaaaaa"
5.  make_password(0) возвращает сообщение "Заполните поле".
   Проверка: len(make_password(0)) == ""
6. make_password(8, has_digit=False, has_upper=False) возвращает строку длиной 8,
   в которой нет ни одной цифры и заглавной буквы.
   Проверка: make_password(8, has_digit=False, has_upper=False) == "aaaaaaaa"
7. Вопрос аналитику: что должна вернуть make_password(1)?
   Пароль из одного символа не может содержать и заглавную, и цифру.
   Сейчас функция возвращает "A1" — строку длиной 2 вместо 1. Это баг.
   Проверка, которая сейчас падает: len(make_password(1)) == 1
