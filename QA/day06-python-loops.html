1. Что такое цикл

Цикл

Конструкция, которая выполняет один и тот же блок кода несколько раз. В Python их два: for — когда заранее известно, по чему идти; while — когда известно только условие остановки.

Разница ощущается на бытовых примерах:

  • for — «проверь каждый товар в корзине». Количество товаров известно, список конечный.
  • while — «наливай воду, пока стакан не полный». Сколько раз — неизвестно, важен только момент остановки.
Итерация

Один проход цикла. Если цикл выполнился 5 раз — было 5 итераций. Слово встретится в автотестах и в документации постоянно.

Зачем это тестировщику. Автотест почти всегда цикл: прогнать один и тот же сценарий на 30 наборах данных, проверить каждую ссылку на странице, дождаться появления кнопки (пока не появится — ждём). Без циклов автоматизации не существует.

На карточку

Чем for отличается от while? — for идёт по готовой последовательности, while крутится, пока истинно условие.

2. for и range

Самый частый цикл в Python выглядит так:

for number in range(1, 4):
    print(number)
1 2 3

Разберём построчно, слово за словом:

  • for — ключевое слово, «для каждого».
  • number — переменная цикла. Имя придумываешь ты. На каждой итерации Python сам кладёт в неё очередное значение.
  • in — «из», указывает, откуда брать значения.
  • range(1, 4) — источник значений: 1, 2, 3.
  • : — двоеточие, как в if. Означает «дальше идёт блок».
  • Отступ в 4 пробела — тело цикла. Всё, что с отступом, повторяется.
range()

Встроенная функция, которая выдаёт последовательность целых чисел. Три формы:

range(5) → 0, 1, 2, 3, 4 — от нуля, пять штук
range(2, 6) → 2, 3, 4, 5 — от 2 до 6, не включая 6
range(0, 10, 3) → 0, 3, 6, 9 — третий аргумент это шаг

Ловушка: правая граница не входит

range(1, 5) — это 1, 2, 3, 4. Пятёрки не будет. Чтобы дойти до числа n включительно, пишут range(1, n + 1).

Это ровно тот же класс ошибок, что баг в discount_levels.py с границей 4999. Ошибка на единицу — самая частая в мире и самая любимая на собеседованиях.

Шаг может быть отрицательным — тогда идём назад:

for i in range(3, 0, -1):
    print(i)
print("Старт!")
3 2 1 Старт!

Обрати внимание: print("Старт!") написан без отступа, поэтому он не в цикле и выполняется один раз, после него.

Ловушка: отступ решает всё

Сдвинь print("Старт!") на 4 пробела вправо — и «Старт!» напечатается три раза. Python не спросит, он просто сделает. Эта ошибка не даёт сообщения об ошибке, она даёт неправильный результат — самый неприятный вид.

Перебор строки

for умеет идти не только по range, а по любой последовательности. Строка — тоже последовательность, из символов:

for letter in "кот":
    print(letter)
к о т

Подробно строки будут на дне 8, сейчас достаточно знать, что так можно.

В тетрадь

Схема цикла for: for переменная in последовательность: + отступ. И три формы range с примерами значений.

3. Накопление: счётчик и сумма

Самая полезная вещь, которую делают циклом, — накапливают результат. Схема всегда одинаковая, из трёх шагов.

# 1. завели переменную ДО цикла
total = 0

# 2. на каждой итерации меняем её
for number in range(1, 5):
    total = total + number

# 3. пользуемся результатом ПОСЛЕ цикла
print(total)
10

Что происходит по шагам:

Итерацияnumbertotal доtotal после
1101
2213
3336
44610
Сокращённая запись

total = total + number пишут короче: total += number. Так же работают -=, *=, /=. Значение то же, читается привычнее для чужого глаза.

Счётчик — частный случай: прибавляем не значение, а единицу.

count = 0
for number in range(1, 11):
    if number % 2 == 0:
        count += 1
print(f"Чётных чисел: {count}")
Чётных чисел: 5

Здесь if живёт внутри for — два уровня отступа. Это нормально и встречается постоянно.

Ловушка: обнуление внутри цикла

Если написать total = 0 внутри цикла, на каждой итерации накопленное будет стираться, и в конце останется только последнее значение. Программа отработает без ошибок и выдаст правдоподобную чушь. Проверяется просто: посчитай ожидаемый результат на бумаге для трёх чисел и сравни.

На карточку

Где объявляется переменная-накопитель? — До цикла. Где используется результат? — После цикла.

4. while

while читается как «пока»: пока условие истинно — повторяй.

count = 3
while count > 0:
    print(count)
    count -= 1
print("Пуск")
3 2 1 Пуск

Условие после while — то же самое, что после if: сравнения, and, or, not. Всё из дня 5 работает здесь без изменений.

Порядок работы:

  1. Python проверяет условие.
  2. Истина — выполняет тело, потом снова возвращается к пункту 1.
  3. Ложь — выходит из цикла и идёт дальше по программе.

Если условие ложно с самого начала, тело не выполнится ни разу. Это не ошибка, а нормальное поведение — и отдельный тест-кейс, о котором забывают.

Ловушка: бесконечный цикл

Убери строку count -= 1 — и count навсегда останется равным 3, условие никогда не станет ложным, программа будет печатать тройку до конца времён.

Остановить: Ctrl+C в терминале. Ничего страшного не произошло, это штатная ситуация, через неё проходят все.

Правило: написала while — сразу глазами найди строку, которая меняет переменную из условия. Нет такой строки — цикл бесконечный.

5. break и continue

break

Немедленно прекращает цикл целиком. Остаток тела не выполняется, следующих итераций не будет, управление уходит на первую строку после цикла.

for number in range(1, 10):
    if number == 4:
        break
    print(number)
1 2 3

На четвёртой итерации сработал break — до print дело не дошло, четвёрка не напечаталась.

continue

Пропускает остаток текущей итерации и переходит к следующей. Цикл продолжается.

for number in range(1, 6):
    if number == 3:
        continue
    print(number)
1 2 4 5

Тройка пропущена, но цикл дошёл до конца. Разница в одном слове, а поведение противоположное.

Ловушка: код после continue недостижим

Всё, что написано в теле цикла после continue на том же уровне отступа, не выполнится никогда. PyCharm подсветит это серым — привыкай замечать серый код, он почти всегда означает ошибку логики.

Бесконечный цикл, из которого выходят по break

Частая и совершенно нормальная конструкция:

while True:
    answer = input("Введите команду (или 'выход'): ")
    if answer == "выход":
        break
    print(f"Выполняю: {answer}")

True — всегда истина, значит условие никогда не станет ложным. Единственный выход — break. Так пишут меню и любые «повторяй, пока пользователь не скажет хватит».

На карточку

break — выйти из цикла совсем. continue — пропустить одну итерацию, цикл продолжается.

6. Цикл внутри цикла

Тело цикла — обычный код, значит внутри может быть ещё один цикл.

for i in range(1, 3):
    for j in range(1, 4):
        print(f"i={i}, j={j}")
i=1, j=1 i=1, j=2 i=1, j=3 i=2, j=1 i=2, j=2 i=2, j=3

Внешний цикл делает один шаг — внутренний успевает прокрутиться целиком. Итого 2 × 3 = 6 строк. Отсюда правило: количество итераций перемножается, и на больших числах это становится больно.

Ловушка: break выходит только из своего цикла

break во внутреннем цикле прерывает внутренний, внешний спокойно идёт дальше. Ожидание «выйдет из обоих» — классическая ошибка новичка.

Разбор по шагам
  1. До цикла: сумма = 0, количество = 0, максимальная цена = 0.
  2. while True — заранее неизвестно, сколько товаров пробьют.
  3. Спросить строку. Если это «стоп» — break.
  4. Иначе превратить во float (цены бывают дробные) и обновить все три переменные.
  5. Максимум: если текущая цена больше сохранённой — перезаписать.
  6. После цикла: если количество равно нулю — сказать «Корзина пуста» и на этом всё.
  7. Иначе посчитать скидку цепочкой if / elif / else и вывести итог.
