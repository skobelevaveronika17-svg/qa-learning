## Часть 2. Переменные (25 минут)

**[Бумага]**

**Переменная** — это имя, за которым хранится значение. Придумываешь имя, кладёшь в него что-то, дальше обращаешься по имени.

```python
name = "Вероника"
age = 26
```

Знак `=` здесь **не равенство**, а присваивание: «положи справа в то, что слева». Читается «name присвоить строку Вероника».

Значение можно перезаписать — переменная хранит последнее:

```python
city = "Минск"
city = "Гомель"
print(city)
```

Выведет `Гомель`. Первое значение потерялось.

Переменные можно использовать друг в друге:

```python
price = 100
quantity = 3
total = price * quantity
print(total)
```

**Правила именования — их придётся соблюдать:**

- Только латиница, цифры и подчёркивание. Кириллица технически работает, но так не делают никогда.
- Не начинается с цифры: `2name` — ошибка, `name2` — нормально.
- Без пробелов: вместо `user name` пишут `user_name`.
- Регистр важен: `Name` и `name` — **разные переменные**. Это источник обидных ошибок.
- Стиль в Python — **snake_case**: строчные буквы, слова через подчёркивание. `user_name`, `total_price`, `is_active`.
- Имя должно говорить, что внутри. `a`, `x`, `dd` — плохо. `user_age`, `order_total` — хорошо. Это не занудство: через месяц ты не вспомнишь, что такое `dd`.

**Попробуй сама.** В том же файле напиши блок с тремя переменными про себя — имя, возраст, город — и выведи их.

## Часть 3. Типы данных (30 минут)

**[Бумага] [Карточка]**

У каждого значения есть тип. Python определяет его сам, но знать типы обязательно — половина будущих ошибок именно про них.

**`int`** — целое число. `26`, `0`, `-5`. Без кавычек.

**`float`** — дробное число. `3.14`, `19.99`. **Разделитель — точка, не запятая.**

**`str`** — строка, текст. Всегда в кавычках: `"Вероника"` или `'Вероника'`. Кавычки любые, но одинаковые с двух сторон. Важно: `"26"` в кавычках — это **строка**, а не число.

**`bool`** — логический тип, два значения: `True` и `False`. **С большой буквы**, это обязательно.

**`None`** — «ничего», отсутствие значения. Не ноль и не пустая строка, а именно пустота. Пригодится позже.

**Как узнать тип:**

```python
age = 26
print(type(age))
```

Выведет `<class 'int'>`.

**Почему это важно — главный пример дня:**

```python
print(2 + 2)      # 4      — сложение чисел
print("2" + "2")  # 22     — склеивание строк
```

Один и тот же плюс делает разные вещи в зависимости от типа. С числами складывает, со строками — соединяет.

А вот так будет ошибка:

```python
print("2" + 2)
```

Python скажет `TypeError`: нельзя складывать строку с числом. Он не догадывается, что ты имела в виду.

**Преобразование типов:**

```python
int("26")      # строка "26" → число 26
str(26)        # число 26 → строка "26"
float("3.14")  # строка → дробное число
```

Работает не всегда: `int("привет")` вызовет ошибку, потому что это не число.

## Часть 4. Ввод данных и f-строки (30 минут)

**[Бумага]**

**`input()`** останавливает программу и ждёт, пока пользователь что-то напечатает и нажмёт Enter:

```python
name = input("Как тебя зовут? ")
print("Привет, " + name)
```

Текст в скобках — приглашение, которое увидит пользователь.

**Ловушка, на которой спотыкаются все:**

```python
age = input("Сколько тебе лет? ")
next_year = age + 1
```

Ошибка `TypeError`. Причина: **`input()` всегда возвращает строку**, даже если ты ввела цифры. `"26"` — это текст, к нему нельзя прибавить единицу.

Правильно:

```python
age = int(input("Сколько тебе лет? "))
next_year = age + 1
print(next_year)
```

Запиши это в тетрадь отдельной строкой: **input всегда возвращает строку.** Ты словишь эту ошибку ещё не раз.

**f-строки** — удобный способ вставлять значения в текст. Перед кавычками ставится буква `f`, а переменные пишутся в фигурных скобках:

```python
name = "Вероника"
age = 26
print(f"Меня зовут {name}, мне {age} лет")
```

Сравни со старым способом:

```python
print("Меня зовут " + name + ", мне " + str(age) + " лет")
```

f-строка читается лучше и не требует преобразований. Пользуйся только ей.

Внутри фигурных скобок можно считать:

```python
price = 100
print(f"Цена с НДС: {price * 1.2}")
```

## Часть 5. Арифметика и комментарии (15 минут)

```python
print(7 + 3)   # 10   сложение
print(7 - 3)   # 4    вычитание
print(7 * 3)   # 21   умножение
print(7 / 3)   # 2.333...  деление, ВСЕГДА даёт float
print(7 // 3)  # 2    целочисленное деление, отбрасывает дробь
print(7 % 3)   # 1    остаток от деления
print(7 ** 3)  # 343  возведение в степень
```

Обрати внимание: `7 / 3` даёт `2.3333`, а `7 // 3` даёт `2`. Второе часто нужно, когда результат должен быть целым — например, сколько полных коробок получится.

**Комментарии** — текст после `#`, который Python игнорирует. Пишутся для людей:

```python
# считаем итоговую стоимость заказа
total = price * quantity
```

## Ошибки, которые ты сегодня увидишь

Не пугайся красного текста — читай последнюю строку, там суть.

**`SyntaxError: invalid syntax`**
Опечатка в структуре: забыта скобка, кавычка, двоеточие. Смотри на строку, указанную в ошибке, **и на предыдущую тоже** — часто скобка не закрыта строчкой выше.

**`NameError: name 'nmae' is not defined`**
Python не знает такого имени. Обычно опечатка в названии переменной или использование её до создания. Проверь регистр: `Name` и `name` — разные вещи.

**`TypeError: can only concatenate str (not "int") to str`**
Пытаешься сложить строку с числом. Нужно преобразование: `int()` или `str()`.

**`ValueError: invalid literal for int() with base 10`**
Пытаешься превратить в число то, что числом не является. Например, `int("привет")` или ввод с запятой вместо точки.

**`IndentationError`**
Проблема с отступами. Сегодня вряд ли встретится, но запомни название — с завтрашних условий и циклов оно станет частым.
