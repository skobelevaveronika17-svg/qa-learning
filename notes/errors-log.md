# Лог ошибок

## День 1 — установка окружения

### Set-ExecutionPolicy: не удаётся привязать параметр "Scope"
Причина: лишний пробел после дефиса — написала `- Scope` вместо `-Scope`.
Решение: имя параметра пишется слитно с дефисом. Копировать команду, а не набирать.

### set-executionPolicy-scopeCurrentUserRemoteSigned: не распознано
Причина: убрала все пробелы, команда слиплась в одно слово.
Решение: структура строки — имя команды, пробел, -Параметр, пробел, значение.

### python.exe: can't open file '2+2'
Причина: написала `python 2+2 print(...) exit` одной строкой. Терминал понял это
как «запусти python и передай ему файл с именем 2+2».
Решение: сначала `python` → появятся `>>>` → потом код по одной строке →
выход через `exit()`.

### git: 'confighh' is not a git command
Причина: опечатка в имени команды.
Решение: Git в конце сообщения сам подсказывает похожую команду — читать до конца.

### git@github.com:...qa-learning.git: не распознано
Причина: вставила только адрес репозитория, без команды перед ним.
Решение: строка всегда начинается с того, ЧТО делать — `git clone адрес`.

### Приглашение сменилось на `>>` и команды не выполняются
Причина: незакрытая кавычка в `git commit -m "текст` — терминал ждёт закрытия.
Решение: `Ctrl+C` отменяет ввод и возвращает нормальное приглашение.
